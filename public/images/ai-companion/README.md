# KIRA character assets

These three character illustrations were generated for this local prototype with
OpenAI's built-in image generation tool on 2026-08-08. KIRA is an original AI
navigator created for the `/ai-companion` experience and is not based on a
character from an existing game or anime franchise.

## Files

- `kira-neutral.webp` — full-body neutral pose.
- `kira-comms.webp` — close communication pose.
- `kira-present.webp` — full-body presentation pose.
- `ai-companion-og.jpg` — route-specific social preview card.

The published WebP files are compressed derivatives of the generated PNGs. The
source PNGs remain in the local Codex generated-images directory for this task.

## Prompt brief

The anchor prompt requested a calm, clever young-adult anime field analyst with
short asymmetrical charcoal hair, a silver forelock, amber-red eyes, and an
original black-and-ivory technical jacket with red lining and restrained cyan
details. It explicitly excluded franchise costumes, logos, weapons, text,
school uniforms, fantasy armor, and recognizable copyrighted elements.

The two follow-up prompts preserved the anchor's identity, costume, palette,
proportions, and rendering style while changing only the pose and expression:
one communication pose and one presentation pose.

The social-card prompt reused KIRA's identity and the finished interface palette
with the exact text `KIRA // SIGNAL DECK`, `AI COMPANION`, and
`THREE INTERFACES. ONE CONTINUOUS MIND.`. The rendered text was checked before
the image was added to route metadata.
